HTML & CSS -Koodiselittäjä

Vasemmalla puolella on koodi ja oikealla puolella sen tarkoitus.

Lähdekoodi

<button class="btn-lataa"> Lataa tiedosto </button>
.btn-lataa { background-color: #4CAF50; color: white; padding: 10px 20px; }
<!-- Kommentti koodissa --> <img src="kuva.jpg" alt="Maisema">

Mitä koodi tekee?

HTML-Painike (Button)

Tämä luo verkkosivulle tavallisen klikattavan painikkeen, jossa lukee teksti "Lataa tiedosto". Luokka (class) auttaa meitä tyylittelemään sen myöhemmin.

CSS-Tyylittely

Tämä muuttaa aiemmin luodun painikkeen taustavärin vihreäksi (#4CAF50), tekstin valkoiseksi ja lisää painikkeen sisälle hieman tyhjää tilaa (padding) reunoille.

Kuvaelementti

Tämä tuo sivulle kuvan. src määrittää kuvan tiedostopolun ja alt-teksti näytetään, jos kuva ei lataudu (tärkeä myös ruudunlukijoille).
